# Atomic File Manager 0.2.0 Beta 1

Android APK prerelease for testing. App version `0.2.0-beta.1`, version code2; Android9/API28 or newer. This beta is based on accepted feature integration through PR#88, not the unfinished plugin drafts or a main/stable release.

## Included

- Internal/SD storage shortcuts, List/Grid views, directional sorting and clearer file-family icons.
- Combined storage capacity with file-type and cleanup analysis started on demand.
- Startup, browse-tab, background-work ownership and file-opening reliability repairs.
- Opening defaults and MIME handling, selected ambiguous PNG identification, remote preparation progress/Cancel and fresh source metadata.
- Focused Image pinch/double-tap zoom, fitted pan limits and recoverable load Retry.
- Audio/Video preparation recovery and shared playback focus/noisy-output handling.
- Eight bundled in-app plugins with separate v0.2 About details and maintained capability records.

## Beta limits

The eight-plugin modernization is ongoing. Advanced Image controls/editing, Editor history, PDF/Document/Markdown session candidates and further Archive inspection work in draft PRs#89–#93 are excluded. Broader providers, media formats, recovery and performance acceptance remain open. Device benchmarks remain deferred. This is a GitHub prerelease, not a Google Play launch or a claim that the full feature/optimization plan is complete.

## Signing and installation

The APK uses the dedicated Atomic release certificate; its public SHA256 fingerprint and APK checksum accompany the download. Keep using that signing identity for future APK updates.

This first dedicated-key beta cannot update an existing debug-signed developer installation of the same package. Existing phone data is preserved: the release process does not uninstall or clear developer builds. Export any app-private information you need before choosing a manual migration; ordinary shared storage files are separate from app-private settings/data.

## Release gates

Before publishing, require exact-head full CI/review, the signed R8 APK's version/package/non-debuggable/signature/hash checks and a smoke run of those exact bytes in disposable API28 and API34 CI emulators. Keep the private keystore/password backup local; upload only the named APK, public provenance manifest, checksums and public certificate fingerprint.
