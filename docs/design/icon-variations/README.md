# Atomic File Manager: folder icon variations

Ten app icon directions built from LLMiser icon study 50, "Markdown Folder". The `#` on the folder front
is replaced by the Atomic mark (three orbits at 0°, 60° and 120°, a nucleus, three electrons). Colours,
borders and shadows follow `docs/design/ATOMIC_DESIGN_SYSTEM.md`: ink `#15171B` on paper `#F4F5F1`,
one accent (Signal `#3A2FF0`, `#8F88FF` on ink), hard offset shadows with no blur (ink on paper, Signal on
ink, `#1D14A0` under the coin and Signal shapes). Each variation has a light and a dark version.

Drawn on a 32 × 32 pixel grid. Generated by `project-docs/brand/make-icons.mjs` in the private MDify-Pro
repo; open `preview.html` to compare them.

| # | Name | Idea |
|---|---|---|
| 01 | Paper & Signal | The brand default: ink on paper, with a single Signal atom where the # was. |
| 02 | Signal Folder | Loud on purpose: a Signal folder carrying a white atom, deep-blue shadow. |
| 03 | Ink Folder | The dark-section look: ink folder, signal-light atom, Signal shadow. |
| 04 | Line Folder | Outline only, like Atomic's stroke icons, lifted on a Signal slab. |
| 05 | Atomic Coin | The Atomic Coin set into the folder front, with its deep-blue offset disc. |
| 06 | Open Folder | The atom rising out of an open folder: opening a folder is the core action. |
| 07 | Stacked | Two folders deep, for a manager of many folders. |
| 08 | Storage Meter | The atom over a storage bar, the first thing Home answers. |
| 09 | Mono Knockout | One colour with the atom cut out, for themed and monochrome icons. |
| 10 | Dot Grid Tab | A Signal tab on Atomic's dot grid: quiet, with one loud detail. |

Files: `svg/atomic-folder-NN-<name>-<light|dark>.svg` (128 × 128) and `png/…-512.png`.
Not wired into the app: the launcher still uses `refract_launcher_art.png`. Pick one and it can be turned
into an adaptive icon (foreground, background and monochrome layers).
