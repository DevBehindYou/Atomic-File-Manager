# Secondary Browse accepted-work retirement

U04 prerequisite: closing, replacing or abandoning a secondary pane stops its listing and operation observers immediately, while already accepted model-owned mutations drain before that exact pane's ViewModelStore is cleared. The primary Activity registry and closed-tab pruning remain separate work.

`BrowseAcceptedWork` counts admission before launch and releases through job completion, including a cancelled scope and cancellation before dispatch. It uses the existing Main-owned ViewModel scope through a lazy provider. Retirement seals new work first and invokes the captured store callback once after the last accepted job. Create, rename, bubble metadata, bubble transfer/cleanup and ordered sort saves participate. Already admitted app-wide queue operations keep their independent ownership. No global mutation scope, blanket NonCancellable work, permission or dependency changes are introduced.
